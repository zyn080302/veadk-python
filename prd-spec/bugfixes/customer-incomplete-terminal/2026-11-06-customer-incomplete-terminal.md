## Background, goals and boundaries
The actual Host recovery callback emits a serialized `skyeyes_result` with status `incomplete` and one of two fixed reasons. `events.py` drops it and the business frontend treats its ordinary final text as success. HTTP200, EOF and turn_complete prove transport termination, not business success. Original incident root_cause_event remains null; this confirmed projection mechanism is not original-incident attribution.
User explicitly authorizes isolated F04 SDK/SSE/history/blocks repair in the task book. Main owns fixed artifacts, merge and PDSA; BugFix2 owns admission/recovery. No shared SDK edits, deployment, push, paid model/MCP, remote shell, budget or source-validation changes.

## Scenarios, design and contracts
FR-1: Preserve only fresh `skyeyes_result` objects with exactly `status: incomplete` and `reason: model_tool_protocol_error` or `host_turn_budget_exhausted`. Reject malformed reserved values with fixed `invalid_result_status`; never copy arbitrary reasons, identity/state/auth or private fields. Existing metadata alias ambiguity remains rejected. Unknown unrelated metadata remains excluded.
FR-2: The result marker requires a nonpartial explicit turnComplete=true model event with plain nonthought text, empty model parts or no content. Tools, user echoes, thought, draft or nonterminal result markers fail. A contentless marker is a real held final; release only after dispatcher success/ACK/cleanup. No extra final or late marker is accepted.
FR-3: Keep transport final/journal completion independent from business failure. Persist the marker, preserve body/usage/tools and incremental purpose-marked prefix, and expose incomplete in business SSE/history/frontend projection. Do not turn a settled incomplete result into permanent blocked admission. Normal completion and a fresh invocation remain unaffected.
Alternative top-level error would turn a valid stopped Host response into SDK channel failure, discard its original public notice and affect recovery. Copying all custom metadata violates isolation. Select bounded display metadata instead. APIs, configuration, dependencies and limits remain unchanged; updated spec CON-2/CON-5/CON-8 owns the contract.
