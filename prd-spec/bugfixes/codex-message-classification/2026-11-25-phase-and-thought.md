# Codex message classification repair

[中文](2026-11-25-phase-and-thought.zh.md)

Change ID: codex-message-classification. Date: 2026-11-25. Status: SDK repair verified; mandatory local repository gates passed; not deployed.

## Evidence and scope
The deployed SDK source merges every completed agentMessage, discarding phase. Completion attributes, assistant history events and choice events also discard thought classification. Synthetic reproduction confirms these mechanisms; original provider events are unavailable, so this is not proof of the original incident's earliest cause. User explicitly requested fixing these diagnosed SDK defects. Other dependencies and Host remain frozen; no customer deployment or cloud replay is authorized.

## Requirements and design
FR-1: Preserve phase from item start/completion and associate deltas by item ID in per-turn state. Commentary, partial_answer and unclassified deltas are partial lifecycle events with text in custom_metadata, not answer parts and not fabricated thoughts. Explicit final_answer deltas continue streaming without buffering. When only legacy unphased items exist, select their last completed message at turn end. Intermediate text must not reach ordinary BFF answer collectors, output_key or durable answer history.
FR-2: Match Codex final selection: last explicit final_answer, otherwise last unphased completed agentMessage. A later legacy message must not replace an explicit final. Batch and streaming paths agree; reasoning/tool events remain separate. Unknown phases are observable but never inferred from text. Only selected final content reaches after-model callbacks. Callbacks retain their existing authority; this change does not classify text generated by a callback or upstream unmarked mixed text.
FR-3: Preserve actual thought classification as reasoning/text in completion attributes, assistant history and choice telemetry, retaining existing content-tracing switches and collection scope.
FR-4: No dependency upgrade, timeout/cap/budget/retry changes, credential access or external model calls. Test repository Codex0.159.2 and original deployment Codex0.162.1 using their unchanged artifacts. Public keyword argument for per-turn phase state is optional; existing callers remain accepted. Legacy unphased streaming becomes visible at final completion, a deliberate safety/latency tradeoff.

Contract: [codex-message-classification](../../../specs/codex-message-classification/README.md). Shared callback merger and other runtimes are unchanged. State lives within one pump and is released on every terminal path; no new task, retry or I/O.
